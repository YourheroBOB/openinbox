# Openinbox 語言、相依套件與執行環境盤點

## 範圍與判讀方式

本盤點根據本次提供的 README、安裝與啟動腳本、架構文件、測試說明及檔案清單整理；不代表已檢查未提供內容的檔案或目前執行中的主機。本文只做評估與規劃，**不升級套件、不變更執行環境，也不宣稱已完成即時漏洞掃描**。

## 已知風險與待確認事項

### 優先處理

1. **Python 最低版本落後於上游支援狀態**：README 與 `install.sh` 都接受 Python 3.9；依上游維護時程，Python 3.9 已結束安全支援。建議另案評估提高最低版本，並先確認部署者實際使用的 Python 版本。
2. **沒有第三方套件鎖定清單**：這符合「標準函式庫、零 pip」的產品設計，但也表示 optional CLI 不在 repo 的依賴版本治理範圍。不能只靠套件管理檔掃描便宣稱整體無已知風險。
3. **執行期能力依平台而異**：SQLite FTS5、SQLite 版本、時區資料與 Bash 版本都沒有集中紀錄或完整相容矩陣。
4. **外部 CLI 版本未治理**：`gog`、`gsk` 與操作者自選的 Agent CLI 是可選工具；升級它們可能影響同步或 Agent 呼叫，也可能改變錯誤輸出。
5. **瀏覽器相容範圍未明訂**：面板和 PWA 缺少可核對的最低瀏覽器版本，且 UI 檢查工具是選用項目。

### 尚無證據確認的事項

- 本次資料未提供 `.github/workflows/smoke.yml` 內容，無法確認 CI 使用哪些 Python 或作業系統版本。
- 未提供正在執行的 Python、SQLite、作業系統、時區資料、瀏覽器或選用 CLI 版本。
- 沒有可據以判定特定第三方套件 CVE 的套件清單；因此本文不指稱有特定套件漏洞。
- 本次僅能記錄已知生命週期與版本治理風險，不能替代正式的依賴、主機或外部 CLI 安全檢查。

## 建議維持的相依原則

- 核心維持 Python 標準函式庫，不為升級計畫直接新增必要 pip、npm、資料庫伺服器或託管服務。
- 選用工具的支援範圍先記錄與測試，再決定是否設最低版本；避免無驗證的自動更新。
- 任何外部 Agent 或郵件工具測試都使用本機 mock／假服務，不呼叫正式服務，也不把郵件內容或憑證寫入測試輸出。
- FTS5 缺席時保留現有 `LIKE` 後備；除非另有明確效能需求，不把 FTS5 改成啟動必要條件。
- 對 Python、SQLite 與時區資料的相容性，以可重現的本機檢查和測試矩陣建立證據；不只依文件宣告推論。
